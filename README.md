# 🛒 QuickBasket – Daily Grocery Helper

QuickBasket is a simple web-based grocery management application that helps users maintain and organize their daily grocery lists.

## 🚀 Features

- Add grocery items
- Select quantity
- Select grocery category
- Mark items as purchased
- Delete items
- Search grocery items
- View total, purchased, and remaining items
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## 🎯 Problem Solved

People often forget grocery items or find it difficult to maintain a simple shopping list.

QuickBasket provides an easy way to add, search, manage, and track grocery items in one place.
